# AI Agent Starter Kit

ชุดเริ่มต้นใช้ AI ช่วยทำงานแบบ "ผู้ช่วยส่วนตัว" ใช้ได้กับ AI หลายตัว (Antigravity, Claude Code, Codex, Cursor, Gemini และอื่นๆ)

เปิดครั้งแรก AI จะ**สัมภาษณ์เราก่อน** ว่าเราเป็นใคร ทำงานอะไร อยากทำอะไร แล้วเสนองานแรกที่ทำเสร็จได้ในวันเดียว ไม่ต้องรู้ก่อนว่าจะให้ AI ทำอะไร

---

## 1. ต้องมีอะไรก่อน

| อย่าง | ใช้ทำอะไร | ราคา |
|---|---|---|
| AI ตัวใดตัวหนึ่ง (แนะนำ Antigravity สำหรับมือใหม่) | ตัวผู้ช่วย | Antigravity ฟรี · Claude Code ต้องมีแพ็กเกจ Pro ขึ้นไป |
| Node.js เวอร์ชัน 22.20 ขึ้นไป | ใช้ติดตั้ง skill | ฟรี |

## 2. ติดตั้ง AI

เลือกตัวเดียวพอ
- **Antigravity (ฟรี):** โหลดที่ https://antigravity.google แล้วล็อกอินด้วย Google
- **Claude Code:** ดูวิธีที่ https://claude.com/claude-code (ต้องมีแพ็กเกจ Claude Pro)

## 3. ติดตั้ง Node.js

โหลดที่ https://nodejs.org กดปุ่ม **LTS** แล้วกด Next ไปเรื่อยๆ จนเสร็จ

## 4. โหลดชุดนี้

กดปุ่มเขียว **Code** ด้านบนหน้านี้ → **Download ZIP** → แตกไฟล์ไว้ที่ Desktop จะได้โฟลเดอร์ `ai-agent-starter-kit`

โฟลเดอร์นี้คือ "บ้าน" ของเรากับ AI งานแต่ละเรื่องให้ทำเป็นโฟลเดอร์ย่อยข้างใน

## 5. ติดตั้ง skill พื้นฐาน 7 ตัว

skill คือ "วิชา" ที่สอน AI ให้ทำงานเป็นขั้นตอน ลงครั้งเดียวใช้ได้ทุกโฟลเดอร์ และใช้ได้ทุก AI

เปิด **PowerShell** (Windows: กด Start พิมพ์ `PowerShell`) หรือ **Terminal** (Mac) แล้ววางทีละบรรทัด กด Enter รอจนขึ้น `Done!` ก่อนวางบรรทัดถัดไป

```
npx skills add obra/superpowers --skill "*" -g -a universal -a claude-code -y
npx skills add mattpocock/skills --skill grill-with-docs -g -a universal -a claude-code -y
npx skills add DietrichGebert/ponytail --skill ponytail -g -a universal -a claude-code -y
npx skills add vercel-labs/skills --skill find-skills -g -a universal -a claude-code -y
```

บรรทัดแรกลงชุด superpowers มาทั้งชุด 15 ตัว (มีตัวที่ใช้ในข้อ 7 อยู่ 4 ตัว ที่เหลือ AI หยิบใช้เองเมื่อจำเป็น) ทั้งหมดจะได้ 18 skill

ที่มาของแต่ละ skill:
- [obra/superpowers](https://github.com/obra/superpowers) — brainstorming, writing-plans, systematic-debugging, verification-before-completion
- [mattpocock/skills](https://github.com/mattpocock/skills) — grill-with-docs
- [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) — ponytail
- [vercel-labs/skills](https://github.com/vercel-labs/skills) — find-skills

## 6. เปิดครั้งแรก

1. เปิด AI แล้วเปิดโฟลเดอร์ `ai-agent-starter-kit` (Antigravity: File → Open Folder)
2. พิมพ์ `สวัสดี`
3. AI จะเริ่มสัมภาษณ์ ถามทีละ 3–4 ข้อ ข้อไหนไม่อยากตอบพิมพ์ `ข้าม` ข้อสุดท้ายจะถามว่าอยากตั้งชื่อให้ AI ไหม (ไม่ตั้งก็ได้)
4. จบแล้ว AI จะสรุปตัวเรา เสนองานแรก 3 ชิ้น และ skill ที่เหมาะกับงานเรา 3 ตัว (ถามก่อนลงทุกครั้ง)

คำตอบเก็บไว้ในไฟล์ `about-me.md` ในเครื่องเราเท่านั้น ไม่ขึ้นอินเทอร์เน็ต อยากให้สัมภาษณ์ใหม่พิมพ์ `สัมภาษณ์ใหม่`

## 7. skill แต่ละตัวใช้ยังไง

ปกติไม่ต้องเรียกชื่อ skill เอง AI หยิบใช้ให้ตามเรื่องที่คุย แต่ถ้าอยากเรียกเอง พิมพ์ชื่อ skill ลงไปในข้อความได้เลย

### grill-with-docs — ให้ AI ซักเราจนแผนชัด
AI ถามทีละรอบ แต่ละข้อมีคำตอบที่มันแนะนำมาให้ ตอบ "ใช่" ก็ไปต่อได้
1. "มีไอเดียขายของออนไลน์ แต่ยังไม่ชัด ช่วย grill ให้หน่อย"
2. "จะเปิดเพจรีวิวอาหาร ช่วยถามจนได้แผนที่ทำได้จริง"
3. "จะย้ายงาน ช่วยถามให้คิดครบก่อนตัดสินใจ"

### brainstorming — คิดไอเดียให้เป็นรูปเป็นร่าง
1. "อยากหารายได้เสริมจากสิ่งที่ถนัด ช่วย brainstorm"
2. "อยากทำคลิป TikTok แต่ไม่รู้จะทำเรื่องอะไร"
3. "อยากได้ระบบจดรายรับรายจ่ายแบบง่ายๆ ควรเป็นแบบไหน"

### writing-plans — แตกงานเป็นขั้นตอน
1. "ทำแผนเปิดร้านออนไลน์ใน 30 วัน เป็นขั้นๆ"
2. "แผนทำเว็บแนะนำตัวเอง ทีละขั้น"
3. "แผนอ่านหนังสือสอบ 2 เดือน"

### ponytail — ให้ AI ทำแบบง่ายที่สุดที่ใช้ได้ ไม่บานปลาย
1. "เขียนสคริปต์เปลี่ยนชื่อรูปทั้งโฟลเดอร์ แบบง่ายสุด"
2. "ทำหน้าเว็บ 1 หน้าแนะนำร้าน ไม่เอาของเกิน"
3. "ไฟล์ Excel นี้รวมยอดขายยังไงให้ง่ายที่สุด"

### systematic-debugging — หาสาเหตุก่อนแก้ เวลาอะไรพัง
1. "สคริปต์ขึ้น error แบบนี้ (วางข้อความ error มา)"
2. "เว็บเปิดในมือถือแล้วหน้าเพี้ยน"
3. "สูตร Excel ได้ตัวเลขผิด"

### verification-before-completion — ห้าม AI บอกว่าเสร็จถ้ายังไม่ได้เช็ก
AI จะลองเปิดหรือรันจริงก่อนบอกว่าเสร็จ ใช้เองอัตโนมัติ
1. "ทำเสร็จแล้วเปิดให้ดูว่าใช้ได้จริง"
2. "เช็กให้หน่อยว่าไฟล์ทั้ง 20 ไฟล์เปลี่ยนชื่อครบ"
3. "ลองกดทุกปุ่มในหน้าเว็บก่อนส่ง"

### find-skills — หา skill ใหม่ที่เหมาะกับงานเรา
1. "มี skill ช่วยทำสไลด์ไหม"
2. "หา skill ที่ช่วยเขียนแคปชันขายของ"
3. "งานฉันคือบัญชี มี skill อะไรช่วยได้บ้าง"

## 8. หา skill เพิ่ม

พิมพ์บอก AI ได้เลยว่าอยากทำอะไร เช่น "หา skill ที่ช่วยทำ ___" AI จะใช้ find-skills ค้นให้ และถามก่อนลงทุกครั้ง หรือดูรายการ skill ยอดนิยมเองที่ https://skills.sh

## ติดปัญหา

- **ขึ้นว่า `npx` ไม่รู้จัก:** ยังไม่ได้ลง Node.js หรือลงแล้วแต่ยังไม่ปิด-เปิด PowerShell ใหม่
- **AI ไม่สัมภาษณ์:** เช็กว่าเปิดโฟลเดอร์ `ai-agent-starter-kit` อยู่ แล้วพิมพ์ `สัมภาษณ์ใหม่`
- **ลบ skill:** `npx skills remove <ชื่อ skill> -g`

## ความปลอดภัย

skill ทำงานได้เต็มสิทธิ์เหมือน AI ลงเฉพาะ skill จากแหล่งที่เชื่อถือได้ และไม่ส่งรหัสผ่านหรือ API key ให้ AI ในแชต
